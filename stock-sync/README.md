# 재고동기화 (SJ와니 · AM)

n세일즈원에서 SJ와니·AM 상품의 **전체주문가능수량**을 **주문가능재고(A)**에 맞춥니다. 주문가능재고가 0 이하인 판매중 상품은 **일시품절**로 바꿉니다. 재고가 있는데 판매종료나 일시품절인 SKU는 패널에서 체크한 것만 판매중으로 돌립니다.

## 설치

- `loader.txt` 내용을 즐겨찾기 URL에 붙여넣습니다. 누를 때마다 main의 최신 코드를 불러옵니다.
- 예비용: `bookmarklet.txt`(코드 전체). F12 콘솔용: `stock-sync.js`

## 사용

1. n세일즈원 아무 화면에서 북마클릿을 누르면 오른쪽 위에 패널이 뜹니다.
2. **대상 추출하고 수량 맞추기**를 누릅니다.
   - 직매입 재고/평가감 현황을 영업부서 S31(패션1팀)로 조회합니다. 2만 건 정도라 약 30초 걸립니다.
   - 속성/SKU명에 `SJ와니`, `SJ WANI` 또는 단독 단어 `AM`이 있고, 상품코드가 `1`로 시작하는 10자리인 것만 대상입니다.
   - 이어서 판매상태/수량관리에서 다건조회로 조회하고, 전체 행을 불러온 뒤 **수량은 확인 없이 바로 저장**합니다(v1.1).
   - 수량 변경이 평소보다 많으면(200건과 전체 SKU의 30% 중 큰 값 초과) 적용 전에 확인을 받습니다.
   - 저장 뒤 다시 조회해서 남은 변경(판매상태 변경 대기, 수량 미반영)을 표로 보여줍니다.
3. 재고가 있는데 판매종료/일시품절인 SKU 중 판매중으로 돌릴 것만 체크합니다. 기본값은 모두 해제입니다.
4. 판매상태를 바꿀 것이 있으면 **③ 판매상태 저장**을 누르고 패널 안 확인창에서 [저장]을 누릅니다. 일시품절 전환과 체크한 판매재개가 저장됩니다.
   - 저장 직전에 다시 조회해서 최신 값 기준으로 적용합니다. 그 사이 바뀐 수량도 함께 맞춥니다.
   - 1000건 단위로 저장하고, 끝나면 ④ 점검을 자동으로 실행합니다.
5. **보고 복사**로 결과를 마크다운으로 복사하거나, **CSV 저장**으로 내려받습니다.
6. 오류가 나면 **[진단 내용 복사]**를 눌러 Claude에게 붙여넣습니다.

## 규칙

- `allOrdPsblQty ≠ ordPsblStockQty`이면 `allOrdPsblQty = ordPsblStockQty`로 바꿉니다(음수도 그대로).
- `ordPsblStockQty ≤ 0`이고 `saleFlag = N`(판매중)이면 `T`(일시품절)로 바꿉니다.
- 판매종료(Y)·일시품절(T)의 판매상태는 체크한 것만 바꿉니다.
  - 일시품절은 `S`(품절해제)로 저장하며, 저장하면 판매중이 됩니다. 2026-11-11 실사용으로 확인했습니다.
  - 판매종료는 `N`(판매중)으로 저장합니다. **아직 실사용 검증 전**이니 처음에는 1건으로 시험하세요.
- 위 두 열 외에는 수정하지 않습니다. 저장 확인창 문구가 「저장 하시겠습니까?」가 아니거나 결과가 「저장 완료」가 아니면 멈춥니다.
- 판매종료 상품은 수량이 반영되지 않을 수 있습니다. 이런 행은 점검에서 '미반영'으로 표시됩니다.
- 화면 요소를 못 찾으면 멈추고 "직접 처리 후 [계속]"으로 안내합니다.

## 디자인

- Montage(wanteddev/montage-web)의 semantic 토큰을 씁니다: foreground/background/surface/line, typography(headline2·label1·label2·caption1·caption2), radius(8·10·12·16), shadow large, Button(small·medium), Checkbox, SectionMessage.
- 폰트는 Pretendard입니다(jsDelivr). 불러오지 못하면 시스템 한글 폰트로 표시됩니다.
- 브랜드 컬러는 Montage blue 대신 **GS SHOP 블루 `#0088FF`**를 씁니다.
- 세일즈원 화면 CSS와 섞이지 않도록 Shadow DOM 안에 그립니다.
