# 변경 이력: 재고동기화 (SJ와니 · AM)

## v1.0 (2026-11-11)
- 첫 버전. 예약 작업(원격 Chrome 자동화)이 로그인 만료로 자주 실패해서, 내 Chrome 세션에서 바로 도는 북마클릿 패널로 옮김
- ① 직매입 재고(S31)에서 SJ와니·AM 상품코드 추출 → ② 판매상태/수량관리 다건조회 + 전체 행 로드 → 변경안 표시
- ③ 패널 안 확인 → 저장 직전 재조회 → 전체주문가능수량 = 주문가능재고(A), 0 이하 판매중 → 일시품절, 1000건 단위 저장 → ④ 자동 점검
- 재고 있는데 판매종료/일시품절인 SKU를 체크박스로 골라 판매중 전환(일시품절→품절해제 S, 판매종료→N)
- 보고 복사(마크다운) · CSV 저장 · [진단 내용 복사] · 요소를 못 찾으면 "직접 처리 후 [계속]"
- 디자인: Montage 토큰 · Pretendard · 포인트 컬러 #0088FF, Shadow DOM
- 검증: ①② 로직은 2026-11-11 실데이터로 확인(대상 86개 / SKU 1,197). 저장 확인창 인식은 빈 저장으로 확인. 같은 날 수동으로 수량 22건 저장, 일시품절→품절해제 4건 성공. ③ 저장을 이 패널로 실사용한 것은 아직 없음
