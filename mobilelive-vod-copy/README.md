# 모바일라이브 [VOD] 편성상품 복사

세일즈원 **아이템 편성 > 모바일라이브** 목록에서 프로그램명에 `[VOD]`가 있고 상품코드가 비어 있는 편성을 찾아,
프로그램명 괄호 안 원방송 일시(예: `(10/1 17시)`)의 편성상품을 복사·저장합니다.

## 파일
- `loader.txt` : **즐겨찾기에 등록할 것(권장).** 누를 때마다 깃헙 main의 최신 코드를 불러와 실행하므로 업데이트돼도 즐겨찾기를 바꿀 필요 없음
- `CHANGELOG.md` : 버전별 변경 이력 (현재 v1.3)
- `bookmarklet.txt` : 코드 전체가 들어 있는 한 줄 (깃헙에 접속이 안 될 때 예비용)
- `mobilelive-vod-copy.js` : 같은 로직의 F12 콘솔용 원본

## 설치 (북마클릿)
1. 크롬 즐겨찾기 바에서 우클릭 > 페이지 추가
2. 이름: `VOD 편성복사`, URL: `loader.txt` 내용 전체 붙여넣기 > 저장 (한 번만 하면 됨)

## 사용
1. 아이템 편성 화면에서 즐겨찾기 `VOD 편성복사` 클릭 (또는 F12 콘솔에 원본 코드 붙여넣기)
2. 자동으로 모바일라이브 탭 → 방송일자 오늘~30일 뒤 → 프로그램명 `와니` → 조회 → 대상 찾기 (패널에서 기간·프로그램명 변경 후 [조회 + 대상 찾기] 가능, AM은 프로그램명만 바꾸면 됨)
3. 오른쪽 위 패널에 대상 목록이 뜸 → 확인 후 **선택 항목 실행**
4. 건마다 상품 복사 + 1번 주력상품 체크까지 자동으로 하고, **저장 전에 패널에서 확인**을 받음
   - `저장` / `이 건 건너뛰기` / `이후 모두 자동 저장` / `중지`
5. 저장 후 목록으로 돌아가 다시 조회해서 상품코드가 채워졌는지 확인하고 결과를 로그에 남김

## 처리 규칙
- 대상: 프로그램명에 `[VOD]` 포함 + 상품코드 비어 있음
- 원방송 일시: 프로그램명 괄호 `(월/일 시)` → 방송 연도 기준(원방송 월이 더 크면 전년도)
- 편성상품 복사 팝업: 방송일자를 원방송 날짜로 조회 → 같은 시각 편성 중 브랜드명(`와니`/`WANI` 또는 `AM`/`아뜰리에`/`마졸리`) 포함 편성 선택.
  여러 개면 `VOD`가 없는(원방송) 편성 우선, 그래도 여러 개면 멈추고 직접 선택 요청
- 상품 편성 화면에 이미 방송상품이 있으면 중복 복사하지 않고 건너뜀
- 더블클릭으로 연 화면의 방송일시·프로그램명이 다르면 방송일시 캘린더 > 프로그램 조회 팝업에서 다시 찾아 들어감
- 화면 요소를 못 찾으면 멈추고 "직접 처리 후 [계속]"을 안내 (그 건만 건너뛰기도 가능)

## 문제가 생기면
패널의 **[진단 내용 복사]**를 누르고 Claude 대화창에 붙여넣기만 하면 됩니다. (멈춤·오류 안내창에도 같은 버튼이 있어요)
