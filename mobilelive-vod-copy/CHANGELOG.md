# 변경 이력: 모바일라이브 VOD 편성상품 복사

## v1.2 (2026-10-22)
- 깃헙 자동 연동: `loader.txt` 즐겨찾기를 한 번 등록하면 누를 때마다 main 브랜치 최신 코드를 불러옴
- 새 버전을 불러오면 화면에 떠 있던 옛 버전 패널을 자동으로 닫고 새로 띄움(실행 중이면 안내)

## v1.1 (2026-10-22)
- 편성상품 복사·프로그램 조회 팝업의 방송일자 자동 입력 보강: 값 직접 설정 → React onChange 호출 → 키보드 입력 → 한 글자씩 입력 순서로 시도하고, 조회 결과에 해당 날짜가 나오는지로 성공을 판단
- [진단 내용 복사] 버튼 추가(패널 상단, 멈춤/오류 안내창에도 있음): 버전·단계·오류·URL·화면 요약·최근 로그·팝업 HTML(축약)을 클립보드로 복사
- 단계 이름(1~9) 기록, 오류·멈춤 이력 보관
- 목록에서 대상 행을 못 찾을 때 목록 상태를 함께 기록, 목록이 갱신 중이면 기다린 뒤 찾기
- 콘솔에서 `__MLCOPY.diag()`로도 진단 복사 가능

## v1.0 (2026-10-22)
- 최초 버전: [VOD] 빈 편성 검출 → 상품코드 더블클릭 → 편성상품 복사(원방송 일시·브랜드 기준) → 1번 주력 체크 → 확인 후 저장 → 목록 검증
- 실사용 결과: 상품 편성 진입은 성공, 복사 팝업 방송일자 입력에서 멈춤 → v1.1에서 보완
