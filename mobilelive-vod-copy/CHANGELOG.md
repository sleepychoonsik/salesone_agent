# 변경 이력: 모바일라이브 VOD 편성상품 복사

## v1.5.2 (2026-10-22)
- 편성 상품 적용 후 확인창('N개의 상품이 등록됩니다')이 늦게 떠서 멈추던 문제: 확인창을 최대 15초 기다리고, 팝업이 닫힐 때까지 늦게 뜨는 확인창도 계속 눌러 줌
- 저장 확인창도 최대 15초(다음 창 6초) 기다림
- 실사용 확인: 조회 → 상품 편성 진입 → 팝업 날짜(달력) → 원본 선택(10/1 17:00 [멀티A]SJ와니) → 적용까지 성공

## v1.5.1 (2026-10-22)
- 팝업이 늦게 뜨는 경우 대비: 편성상품 복사 팝업은 최대 15초, 날짜칸·목록이 그려질 때까지 최대 12초, 조회 결과는 최대 12초 기다림. 달력·프로그램 조회 팝업 대기도 늘림
- 캐시 지연 해소: 실행 시 깃헙 최신 커밋을 직접 확인해서 더 새 버전이 있으면 그 버전으로 바로 실행(다음 업데이트부터 5분 기다릴 필요 없음)

## v1.5 (2026-10-22)
- 팝업 인식 수정: 팝업(MUI Dialog, 화면 본체 밖)을 정확히 잡도록 변경. v1.4.2는 팝업 대신 뒤에 숨은 아이템 편성 화면의 날짜칸을 바꾸고 있었음(진단으로 확인)
- 팝업 목록이 TOAST 그리드가 아니어도 'YYYY-MM-DD HH:MM' 칸 기준으로 행(방송일시·프로그램명)을 읽어 선택
- 팝업 날짜를 못 바꿔도 기본 조회 기간(한 달)에 원방송 날짜가 들어 있으면 그대로 찾아서 진행
- 프로그램 조회 팝업도 같은 방식으로 처리

## v1.4.2 (2026-10-22)
- 즐겨찾기를 여러 번 눌러도 조회가 겹쳐 실행되지 않도록 막음
- 참고: 깃헙 원본은 최대 5분 캐시되어, 업데이트 직후 몇 분은 이전 버전이 뜰 수 있음(패널 제목의 버전으로 확인)

## v1.4.1 (2026-10-22)
- 진단 내용에 달력(열려 있으면)·날짜칸 HTML과 달력 인식 결과 포함

## v1.4 (2026-10-22)
- 날짜를 달력 클릭으로 고르도록 변경: 날짜칸 클릭 → 두 달 달력에서 시작일·종료일 클릭(필요하면 ‹ › 로 달 이동). 세일즈원 날짜칸은 값을 직접 넣어도 반영되지 않음(v1.3 실사용에서 확인)
- 프로그램명이 '와와니'처럼 이어 붙던 문제 수정: 프로그램명은 덮어쓰기만 하고, 날짜 재시도에 섞지 않음
- 화면을 망가뜨릴 수 있는 키보드 입력 방식 재시도 제거

## v1.3 (2026-10-22)
- 실행하면 바로 아이템 편성 > 모바일라이브 탭 선택 → 방송일자(오늘 ~ 30일 뒤) · 프로그램명(와니) 입력 → 조회 → 대상 찾기까지 자동
- 패널에서 방송일자·프로그램명을 바꿔 [조회 + 대상 찾기] 가능 (프로그램명과 기간 길이는 브라우저에 기억)
- 조회 결과가 입력한 기간·프로그램명과 맞는지 확인해서, 화면에 반영 안 되면 다른 입력 방식으로 재시도

## v1.2 (2026-10-22)
- 깃헙 자동 연동: `loader.txt` 즐겨찾기를 한 번 등록하면 누를 때마다 main 브랜치 최신 코드를 불러옴
- 새 버전을 불러오면 화면에 떠 있던 옛 버전 패널을 자동으로 닫고 새로 띄움(실행 중이면 안내)

## v1.1 (2026-10-22)
- 편성상품 복사·프로그램 조회 팝업의 방송일자 자동 입력 보강: 값 직접 설정 → React onChange 호출 → 키보드 입력 → 한 글자씩 입력 순서로 시도하고, 조회 결과에 해당 날짜가 나오는지로 성공을 판단
- [진단 내용 복사] 버튼 추가(패널 상단, 멈춤/오류 안내창에도 있음): 버전·단계·오류·URL·화면 요약·최근 로그·팝업 HTML(축약)을 클립보드로 복사
- 단계 이름(1~9) 기록, 오류·멈춤 이력 보관
- 목록에서 대상 행을 못 찾을 때 목록 상태를 함께 기록, 목록이 갱신 중이면 기다린 뒤 찾기
- 콘솔에서 `__MLCOPY.diag()`로도 진단 복사 가능

## v1.0 (2026-10-22)
- 최초 버전: [VOD] 빈 편성 검출 → 상품코드 더블클릭 → 편성상품 복사(원방송 일시·브랜드 기준) → 1번 주력 체크 → 확인 후 저장 → 목록 검증
- 실사용 결과: 상품 편성 진입은 성공, 복사 팝업 방송일자 입력에서 멈춤 → v1.1에서 보완
