# 장기무이자(방송중 무이자) 세팅 자동화

n세일즈원 상품조회/수정 > 가격/프로모션의 방송중 무이자 세팅(기본 10개월, 2~12개월 선택)을 한 번에 처리하는 북마클릿.

## 설치
- `loader.txt` 내용을 즐겨찾기 URL에 붙여넣기 (누를 때마다 main의 최신 코드를 불러옴)
- 예비용: `bookmarklet.txt`(코드 전체), F12 콘솔용: `installment-free-setting.js`

## 사용
1. n세일즈원 아무 화면에서 북마클릿 클릭 → 우측 패널
2. 상품코드(줄바꿈), 방송 시작·종료 입력 (예: `2026-11-06 09:25`)
   - 개월수: 패널에서 고른 개월수(기본 10)가 전체에 적용. 상품별로 다르게 하려면 코드 뒤에 개월수 (예: `1131710679 6`)
   - [전체 상품에 일괄 적용]: 고른 개월수를 모든 상품코드 뒤에 적어 넣음
3. ① 미리보기 → 표 확인 (처음 실행 시 "조회 버튼을 눌러주세요"가 뜨면 세일즈원 [조회] 1회 클릭)
4. ② 실행 → 직매입(및 위수탁 3개월 이하)은 끝까지, 위수탁 4개월 이상은 합의요청까지
5. 노란 상자의 상품코드로 협력사 합의 요청
6. 승인 후 같은 입력으로 ① → ③ 위수탁 2단계 (가격 원복 + 기존 무이자 복구)
7. ③에서 다시 노란 상자가 뜨면 기존 무이자 복구 합의도 요청
8. 오류가 나면 [진단 내용 복사] → Claude에게 붙여넣기

## 규칙
- 무이자 구간: 방송 -30분 ~ +30분(…:59초), 기존 무이자는 1초 전 종료, 다음 분부터 복구(기존 개월수·부담율·종료일)
- CATV만 등록 → 인터넷·T커머스 자동 생성
- 당사 무이자 할부 규정(판매가별 최대 개월): 5만 미만 없음 / 5~10만 미만 3개월 / 10~20만 미만 9개월 / 20만 이상 12개월
  - 규정 안: 가격 변경 없이 기존 무이자 종료 → 방송중 무이자 → 기존 무이자 복구
  - 규정 밖: 그 개월수의 기준가(3개월 이하 50,000 / 4~9개월 100,000 / 10~12개월 200,000)로 올린 뒤 세팅, 원복은 직전가 대비 41% 이내 n차(900원 끝)
  - 13개월 이상은 품의 대상이라 지원하지 않음
- 직매입: 당사 100%, 합의 없음, 기준가 노출 약 1분
- 위수탁 3개월 이하: 당사 100%, 합의 없이 직매입처럼 한 번에 처리
- 위수탁 4개월 이상: 당사 50/업체 50, 반드시 협력사 합의 요청(화면 저장과 같은 요청), 가격은 마진 48%(업체지급 = 판매가×0.52)
  - 기준가 인상은 기본 방송 전날 03:00 예약 → 승인 후 아직 시작 전이면 예약 삭제(노출 0)
- 이미 등록된 방송중 무이자·복구는 건너뜀, 기존 무이자가 같거나 더 긴 상품도 건너뜀, 진행 중인 합의가 있으면 건너뜀
- 실행 후 기준가가 마지막 가격으로 남으면 ⚠ 표시
