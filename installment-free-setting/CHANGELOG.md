- 디자인 시스템 "세일즈원 자동화 UI"(`design/so-ui.css`) 적용: Shadow DOM 패널, 단계 표시, 숫자 카드, 표, 접기 버튼, 접히는 진행 로그
- 실행 전 확인을 브라우저 확인창 대신 패널 안 확인창([실행]/[취소])으로 변경
- 협력사 합의 요청 상자를 주의 메시지 + [합의 요청 목록 복사]로 변경
- 미리보기 표를 5열로 정리: 가격 단계는 "할 일" 아래, 무10 분담은 "기존 무이자" 아래. 버튼 이름은 "② 실행", "③ 위수탁 2단계"로 줄이고 설명은 아래 안내문으로
- API 처리 로직은 그대로. 가짜 화면에서 패널 표시만 확인했고 세일즈원 실화면에서는 아직 실행 전

## v1.0 (2026-11-04)
- 첫 버전. 상품코드 + 방송 시작·종료 입력 → ① 미리보기 → ② 실행 → ③ 위수탁 2단계
- 직매입: 기존 무이자 종료 → 200,000(약 1분) → 무10(당사 100) → 가격 원복(직전가 대비 41% 이내 n차) → 기존 무이자 복구
- 위수탁: 무10(당사 50/업체 50)은 화면 저장과 같은 협력사 합의 요청으로만 등록, 가격은 마진 48%(업체지급 = 판매가×0.52)
  - 200,000은 기본 방송 전날 03:00 예약 → 승인 후 아직 시작 전이면 예약 삭제(노출 0), 이미 적용 중이면 n차 원복
  - 기존 무이자 복구는 업체부담 > 0 이면 합의 요청, 진행 중인 합의가 있으면 보류
- CATV만 등록(인터넷·T커머스 자동 생성), 이미 등록된 무10·복구는 건너뜀
- 로그인 정보: 세일즈원 요청 헤더에서 가져옴. 없으면 [조회] 한 번 누르도록 안내(협력사 합의 화면으로 자동 이동하면 브라우저가 멈춰서 제외)
- [진단 내용 복사]: 버전·단계·입력·미리보기 결과·오류·쓰기 요청 기록·로그 (로그인 정보 제외)
- 검증: 2026-11-06 방송 실제 데이터로 미리보기 분석 로직 확인. ②·③ 실행은 이 스크립트로는 아직 실사용 전(같은 요청은 11/03~04 수동 작업에서 성공)
