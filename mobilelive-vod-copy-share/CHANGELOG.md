# 변경 이력: 모바일라이브 VOD 편성상품 복사 — 공유용

## v1.2 (2026-11-11)
- 디자인 시스템 "세일즈원 자동화 UI"(`design/so-ui.css`) 적용: Shadow DOM 패널, 대상 목록·체크박스, 패널 안 확인창, 접기 버튼, 접히는 진행 로그
- 버튼 이름 "조회 + 대상 찾기" → "조회하고 대상 찾기". [대상 다시 찾기]는 목록 제목 옆, [진단 내용 복사]는 패널 아래로 이동
- 화면 조작·저장 로직은 그대로. 가짜 화면에서 패널 표시·버튼 클릭만 확인했고 세일즈원 실화면에서는 아직 실행 전

## v1.1 (2026-11-09)
- 오류 수정: 원본 편성을 고른 직후 바로 [편성 상품 적용]을 눌러, 원본 상품 목록을 다 불러오기 전에 적용되면서 "알림상품코드 등록 처리중 오류… 비어 있을 수 없습니다"가 나던 문제
- 원본 선택 후 팝업의 상품 목록(상품코드)이 다 뜨고 개수가 안정될 때까지 기다린 뒤 적용(최대 10초, 못 찾으면 1.5초 대기 후 진행)
- 그래도 같은 오류가 나면 확인창을 닫고 한 번 더 기다렸다가 자동으로 다시 적용(저장 전 단계라 안전). 두 번째도 실패하면 기존처럼 멈추고 안내

## v1.0 (2026-11-04)
- `mobilelive-vod-copy` v1.7(SJ와니 전용)을 바탕으로 만든 공유용 첫 버전. 화면 조작·저장·검증 로직은 v1.7과 동일
- 패널에 [브랜드] 칸 추가: 첫 단어 = 프로그램명 조회어, 쉼표로 여러 표기(대소문자 무시)를 같은 브랜드로 매칭
- 브랜드 입력값은 브라우저에 기억(조회 기간 일수와 함께). 브랜드가 비어 있으면 자동 조회하지 않고 입력을 안내
- 진단 내용에 브랜드 조회어·매칭 표기 추가
- 원본과 동시에 써도 겹치지 않게 패널·설정 저장 키·자동 업데이트 이름을 분리
