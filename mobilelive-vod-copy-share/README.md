# 모바일라이브 [VOD] 편성상품 복사 — 공유용(브랜드 입력)

[`mobilelive-vod-copy`](../mobilelive-vod-copy)(SJ와니 전용)와 같은 기능에서 **브랜드만 패널에 직접 넣어** 쓸 수 있게 한 버전입니다.
다른 브랜드 담당자에게 공유할 때 이 폴더의 `loader.txt`를 주면 됩니다. 원본 SJ와니 버전은 그대로 둡니다.

세일즈원 **아이템 편성 > 모바일라이브** 목록에서 프로그램명에 `[VOD]`가 있고 상품코드가 비어 있는 편성을 찾아,
프로그램명 괄호 안 원방송 일시(예: `(10/1 17시)`)의 편성상품을 복사·저장합니다.

## 파일
- `loader.txt` : **즐겨찾기에 등록할 것(권장).** 누를 때마다 깃헙 main의 최신 코드를 불러와 실행
- `CHANGELOG.md` : 버전별 변경 이력 (현재 v1.0)
- `bookmarklet.txt` : 코드 전체가 들어 있는 한 줄 (깃헙 접속이 안 될 때 예비용)
- `mobilelive-vod-copy-share.js` : 같은 로직의 F12 콘솔용 원본

## 설치 (북마클릿)
1. 크롬 즐겨찾기 바에서 우클릭 > 페이지 추가
2. 이름: `VOD 편성복사(공유)`, URL: `loader.txt` 내용 전체 붙여넣기 > 저장

## 사용
1. 아이템 편성 화면에서 즐겨찾기 클릭
2. **처음 한 번 [브랜드] 칸 입력** → [조회 + 대상 찾기]
   - 첫 단어가 프로그램명 조회어, 쉼표로 여러 표기를 넣으면 전부 같은 브랜드로 인식
   - 예: `와니, WANI` / `라삐아프` / `마졸리, MAJOLI`
   - 입력값은 이 브라우저에 기억돼서 다음부터는 바로 조회됨
3. 대상 목록 확인 후 **선택 항목 실행**
4. 건마다 상품 복사 + 1번 주력상품 체크까지 자동, **저장 전에 패널에서 확인**
   - `저장` / `이 건 건너뛰기` / `이후 모두 자동 저장` / `중지`
5. 저장 후 목록을 다시 조회해 상품코드가 채워졌는지 확인하고 결과를 로그에 남김

## 처리 규칙
- 대상: 프로그램명에 `[VOD]` 포함 + 상품코드 비어 있음 + 브랜드 표기 포함
- 원방송 일시: 프로그램명 괄호 `(월/일 시)` → 방송 연도 기준(원방송 월이 더 크면 전년도)
- 편성상품 복사 팝업: 원방송 날짜로 조회 → 같은 시각 편성 중 브랜드 표기가 들어간 편성 선택.
  여러 개면 `VOD`가 없는(원방송) 편성 우선, 그래도 여러 개면 멈추고 직접 선택 요청
- 상품 편성 화면에 이미 방송상품이 있으면 중복 복사하지 않고 건너뜀
- 화면 요소를 못 찾으면 멈추고 "직접 처리 후 [계속]"을 안내

## 문제가 생기면
패널의 **[진단 내용 복사]**를 누르고 Claude 대화창에 붙여넣기만 하면 됩니다.
